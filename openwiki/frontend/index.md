# Files

- [Web app shell, routing and auth](app-shell-and-routing.md) - How the Next.js App Router frontend is assembled — the single server layout and its load-bearing provider order, the client-side app shell and route map, the Supabase session middleware that refreshes cookies and gates user-scoped routes, the password, magic-link and OAuth sign-in flows with a same-origin return-path guard, the identity context, and the typed openapi-fetch client whose middleware attaches the bearer token and mints idempotency keys behind the /api/be proxy.
- [Chat widget and streaming client](chat-and-streaming-client.md) - How the web app hosts the agent — the floating ChatWidget with its compact and docked layouts and signed-out gate, the useAgentStream hook that posts to /agent/stream direct-to-origin with the Supabase token and turns typed Server-Sent Events into a streaming assistant bubble, activity trail, side panels and follow-up chips, the bespoke SSE parser and panel identity contract, human-in-the-loop resume, history hydration and legacy claim, stop/retry/regenerate semantics, smooth reveal, and the rateability rule behind message feedback.
- [Internationalization and theming](i18n-and-theming.md) - How the web app localizes and themes itself — cookie-based next-intl locale resolution without URL routing, the en/vi message catalogs and the tests that keep them in parity with each other and with the backend's supported languages, how the UI locale differs from the agent's detected reply language and the side-panel language, dark mode via next-themes with a class-based Tailwind variant, and the design-token system whose colors flip between themes through CSS-variable indirection.
- [Trip research UI](trip-research-ui.md) - The web client for trip research. Covers the Research tab on the trip page (locked, empty, running and finished states, origin prompt, revise and run-again), the typed research client and the SSE parser and hook for the progress stream, the plan view built from proposal.json with apply-to-trip, and the chat's research watch, done card and derived research-plan side panel.
- [Trips, bookings and catalog pages](trips-bookings-and-catalog-pages.md) - The feature pages of the web app and how they consume the REST surface through per-domain TanStack Query hooks — the trips list and the tabbed trip detail (today, itinerary, budget, expenses, bookings, shortlist, map), the bookings table with client-side filtering and cancellation, the flights and hotels search pages that reuse the chat's result cards, the saved-places page with its browse drawer and optimistic flags, the city guide, and the full-replace, optimistic-update and typed-conflict conventions the hooks follow.
