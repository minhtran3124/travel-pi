# Files

- [Agent evaluation harness](agent-eval-harness.md) - How the agent's behaviour is measured — the framework-free evalkit engine (typed goldens, five ports, a metric registry with deterministic, trajectory, judged and oracle families, a k-repeat runner, JSON and HTML reports, and a baseline comparison that is the regression gate) and the travel-pi binding that drives the real LangGraph graph with production agent config, recomputes ground truth from the seeded database, groups goldens by capability and scenario, and the smoke, full, baseline, compare and check targets with the rule that the judged suite never runs on CI.
- [Backend test strategy](backend-test-strategy.md) - How the FastAPI backend is tested — the pytest layout by layer, the session-scoped client fixture that swaps exactly two dependencies (the database session and the authenticated user) to run the real app against a temporary SQLite file or a Postgres URL, the fixtures that repoint settings for tools and RAG, the deterministic FakeLLM and graph injection that keep agent tests offline, the architecture tests that enforce layering and language conventions, environment pitfalls, and the Docker Postgres run that proves cross-engine parity.
- [Frontend unit tests and Playwright e2e](frontend-tests-and-e2e.md) - How the web app is tested — the Vitest and Testing Library unit runner with a load-bearing setup file that makes the relative-URL API client and the Supabase browser client work under Node, Mock Service Worker handlers registered per test, colocated component and hook tests, and the opt-in Playwright suite that signs in once through a setup project, reuses the saved session, loads credentials the same way next dev does, skips cleanly without secrets, and assumes a running backend.
